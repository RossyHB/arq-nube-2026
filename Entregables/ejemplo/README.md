## Resumen del proyecto

**TurnApp** — App web para gestión de turnos médicos, dockerizada, con propuesta de infraestructura en AWS.

| | |
|---|---|
| **App** | Node.js + PostgreSQL |
| **Docker** | `docker compose up` en `app/` |
| **DB** | PostgreSQL (relacional) |
